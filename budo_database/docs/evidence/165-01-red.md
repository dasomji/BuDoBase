## Bounded contract

- Unsupported kid-edit preflight diagnostics contain only a stable 1-based
  child ordinal, structural path, and encoded byte count. They contain no
  child/Turnus identifier keys, injected relation IDs, or database values.
- `check_audit_security_readiness` reads an explicit JSON manifest path. Its
  exact top-level, candidate-preflight, control, and approval keys are pinned.
- Honest blocked evidence passes ordinary lint but fails `--require-approved`;
  a synthetic complete approval passes that gate.
- Representative missing/extra keys, placeholder assertions, unsafe evidence
  references, invalid/future dates, count/size/status inconsistencies, and
  invalid approvals are rejected.
- Rejections expose only the affected JSON pointer and a fixed reason; injected
  manifest values are never echoed.
