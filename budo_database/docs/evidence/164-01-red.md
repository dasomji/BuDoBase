## Focused direct-PostgreSQL RED run

unique temporary database was created and dropped with `psycopg2` (the image has
no `psql` executable). Command under test:

```text
python manage.py test budo_app.audit_tests.test_kid_edit_audit_schema --verbosity 2
```

Result: expected RED, exit 1 — 9 tests ran in 3.997 seconds, with 33 subtest
failures and 1 error. The failures identify the two absent production seams:

- `budo_app.kid_edit_audit.validate_kid_edit_details` and its 4 MiB constant do
  not exist;

Both legacy regression tests passed, proving the pre-existing generic validator
is green at this fixed point. Django migrations and system checks also completed.
