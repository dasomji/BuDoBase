## Authoritative contract

The tests follow #158's stable-list and auditable-access specification:

- first-request `snapshot_id`, explicit zero sentinel, `id <= snapshot_id`,
  reuse across pages, and rejection of negative, noninteger, or future values;
- stable offset pagination after newly appended access/source rows;
- a query-level projection that does not load the `details` JSON column,
  bounded `details_summary` for every action, exact `kid.edit` summary, no full
  `details`, and one `details_url` per row;
- one metadata-only generic-schema `audit.view` event after response
  materialization and before delivery, using outer resource
  `audit_log/<turnus-id>`;
- 503 with no event payload if access-event validation/insertion fails;
- exact private/no-store, pragma, cookie-vary, no-referrer, and nosniff headers.

The legacy HTTP assertion now includes the required pagination snapshot field.
