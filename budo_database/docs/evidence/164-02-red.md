## Public contracts specified

`budo_app/audit_tests/test_kid_edit_audit_snapshot.py` defines a bounded public
surface for:

- frozen, redacted `LoadedKidEditPeriod`, `LoadedKidEditFocusLink`,
  `LoadedKidEditEvent`, and `LoadedKidEditAssignment` DTOs;
- `serialize_kid_edit_snapshot`, consuming an already-loaded child plus explicit
  active periods, focus links, events, and assignments with zero internal queries;
- `build_kid_edit_audit_details(before, after, changed_paths)`, delegating to the
  dedicated schema validator with the same `expected_changed_paths` plan;
- `sign_kid_edit_command` and `verify_kid_edit_command_fingerprint` over the
  existing complete `ValidatedKidEditCommand`.

The snapshot fixture covers all 27 raw storage values (including null, empty,
case, whitespace, placeholder strings, and a date), chronological periods with
empty/multiple focus sets, casefold/ID focus ordering, supplied-active-set
cross-Turnus omission, all three Happy Cleaning targets, assignment versions,
event revisions and labels, corrupt cross-event station fail-close behavior,
fresh deep plain JSON, redacted reprs, and frozen DTOs.

The fingerprint fixture requires the exact 79-character
`hmac-sha256:v1:<64 lowercase hex>` form, dedicated
`budo.kid-edit.command-fingerprint.v1` salt, deterministic canonical typed
ordering of every normalized command component, key and payload sensitivity,
SECRET_KEY fallback verification, compare-all-keys constant-time checks,
malformed-input false results, and no canonical payload in return values, logs,
or reprs.
